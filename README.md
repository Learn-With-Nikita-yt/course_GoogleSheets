# Google Sheets for Data Analysis

Welcome to the **Google Sheets for Data Analysis** course!

In this hands-on course, we'll explore how to use Google Sheets for real-world data analysis—from importing and preparing raw data to building an interactive analytical dashboard.

Google Sheets is a powerful and accessible tool for working with data. Here are a few reasons why it's a great starting point for aspiring data analysts:

- **Free to use:** Google Sheets is available at no cost with a personal Google account.
- **Accessible anywhere:** Work with your spreadsheets through a web browser on different devices.
- **Real-time collaboration:** Share spreadsheets and work with others simultaneously.
- **Google ecosystem integration:** Connect with services such as Google Drive, Google Forms, and other Google tools.
- **Extensible functionality:** Use built-in functions, add-ons, and integrations to expand what's possible.

The goal of this course isn't simply to learn spreadsheet functions. It's to understand the **end-to-end data analysis process** and apply it to a practical project.

## What You'll Learn

### 1. Importing Data from Different Sources

We'll explore several ways to bring data into Google Sheets:

- Importing data from websites
- Importing Excel files
- Importing CSV files
- Importing data from other Google Sheets

### 2. Data Preparation

Before analyzing data, we need to understand its structure and ensure its quality.

In this section, we'll cover:

- **Data profiling:** Exploring datasets, understanding their structure, and identifying potential issues
- **Data cleaning:** Handling missing values, duplicates, and inconsistent data
- **Data quality checks:** Validating data before using it in calculations and reports

### 3. Data Transformation and Analysis

Once our data is clean, we'll transform it into useful information.

You'll learn how to:

- Use Google Sheets formulas for data analysis
- Perform calculations and transform data
- Summarize and explore data using pivot tables

### 4. Building an Interactive Dashboard

Finally, we'll bring everything together in an analytical dashboard.

We'll cover:

- Creating charts and visualizations
- Adding interactive elements
- Organizing metrics and reports
- Building a dashboard to explore and communicate insights

By the end of the course, you'll have experience working through a complete data analysis workflow—from raw data to a finished dashboard.

## Getting Started

### 1. System Requirements

You'll need a desktop or laptop computer running Windows, macOS, Linux, or another operating system with a compatible modern web browser.

While Google Sheets is also available on mobile devices, **I recommend using a computer for this course**, as we'll work with larger datasets, formulas, pivot tables, and dashboards.

For more details, see Google's official [system requirements and supported browsers](https://support.google.com/docs/answer/2375082?hl=en).

### 2. Google Account

You'll need a Google account to create, edit, and save your spreadsheets.

If you don't already have one, follow Google's instructions to [create a Google account](https://support.google.com/accounts/answer/27441?hl=en).

Once you're signed in, you can open [Google Sheets](https://sheets.google.com/) and create your first spreadsheet.

### 3. Web Browser

Google Sheets works with modern web browsers, including Google Chrome, Microsoft Edge, Firefox, and Safari.

I recommend using an up-to-date version of **Google Chrome** for the most consistent experience while following the course.

If you don't have it installed, you can download it from the [official Google Chrome website](https://www.google.com/chrome/).

Other supported browsers should work as well, although some interface elements may look slightly different.

## Open Data Resources

Looking for more datasets to practice your analytical skills?

Here are some excellent resources where you can explore publicly available datasets, discover project ideas, and continue learning data analytics.

### General Datasets and Learning Resources

- **[Kaggle](https://www.kaggle.com/datasets)** — A popular platform offering datasets, notebooks, competitions, and learning resources. A great starting point for your first data analytics projects.

- **[Google Dataset Search](https://datasetsearch.research.google.com/)** — A search engine that helps you discover datasets published across the web.

- **[UCI Machine Learning Repository](https://archive.ics.uci.edu/)** — A collection of datasets commonly used for data analysis, statistics, and machine learning.

- **[Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets)** — A community-maintained GitHub repository featuring datasets organized by topic.

### Government and Public Data

- **[NYC Open Data](https://www.nyc.gov/opendata)** — Public datasets from New York City, covering transportation, housing, public services, and more.

- **[Statistics Canada](https://www.statcan.gc.ca/en/start)** — Official Canadian statistics covering population, employment, the economy, education, and other topics.

- **[Australian Bureau of Statistics](https://www.abs.gov.au/)** — Official statistics and datasets about Australia's population, economy, businesses, and society.

- **[Data.gov](https://data.gov/)** — The United States government's open data portal, featuring datasets from federal agencies and other participating organizations.

- **[European Data Portal](https://data.europa.eu/en)** — The official portal for discovering open datasets from European institutions and countries.

### Economics, Finance, and Global Development

- **[World Bank DataBank](https://databank.worldbank.org/)** — Explore international economic, social, and development indicators.

- **[Nasdaq Data Link](https://data.nasdaq.com/search)** — Financial, economic, and alternative datasets for research and analysis. Some datasets and services require paid access.

- **[UN Data](https://data.un.org/)** — Statistical datasets and resources from the United Nations.

**Tip:** When choosing a dataset for your first project, start with something manageable. Look for a dataset with clear column names, a reasonable number of records, and questions you'd genuinely like to answer.

Also, check the dataset's license and usage terms before downloading, modifying, or publishing your work.
